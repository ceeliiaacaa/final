💡 ¿Qué es una página web?

Una página web es un documento digital que se encuentra almacenado en un servidor y que puede ser visualizado a través de un navegador. Estas páginas están creadas con lenguajes como HTML, CSS... que permiten estructurar el contenido, darle estilo y añadir interactividad. Cada página web tiene una dirección única llamada URL que permite acceder a ella desde cualquier parte del mundo.

🖥️ ¿Qué es un sitio web?

Un sitio web es un conjunto de páginas web relacionadas entre sí. Todas estas páginas están conectadas mediante enlaces internos y forman una estructura organizada que permite al usuario navegar fácilmente por la información.

📡 Cómo funciona Internet

Internet es una red global que conecta millones de dispositivos en todo el mundo. Funciona mediante la comunicación entre servidores (que almacenan la información) y clientes (como tu ordenador o móvil). Cuando escribes una dirección web, tu dispositivo envía una petición que viaja por la red hasta llegar al servidor correspondiente, el cual responde enviando los datos necesarios para mostrar la página.

🧭 DNS

l DNS (Domain Name System) es un sistema que traduce los nombres de dominio, como google.com, en direcciones IP numéricas que los ordenadores pueden entender. Esto es necesario porque las máquinas no trabajan con nombres, sino con números. Gracias al DNS, los usuarios pueden recordar fácilmente las páginas web sin necesidad de memorizar direcciones IP complejas.

🌐 Dirección IP

Una dirección IP es un identificador único que se asigna a cada dispositivo conectado a Internet. Es como una “matrícula digital” que permite que los dispositivos se reconozcan entre sí y puedan enviar y recibir información correctamente.

🔒 HTTP y HTTPS

HTTP es el protocolo que se utiliza para transferir información en la web. HTTPS es una versión mejorada y segura de HTTP, ya que cifra los datos para proteger la información del usuario. Esto es especialmente importante cuando se envían contraseñas, datos personales o información sensible a través de Internet.

📦 Transferencia de datos

Se envía la información en pequeños paquetes. Estos paquetes viajan por diferentes rutas dentro de la red hasta llegar a su destino, donde se vuelven a unir para formar la información completa. Este sistema permite que Internet sea rápido, eficiente y estable incluso cuando hay mucho tráfico.
