📄 ¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje utilizado para crear la estructura de las páginas web. Con HTML se define qué elementos aparecen en la página, como títulos, párrafos, imágenes o enlaces.

🏷️ Etiquetas HTML

  • <html>: contiene toda la página.
  • <head>: información de configuración.
  • <body>: contenido visible.
  • <h1>: títulos.
  • <p>: párrafos.
  • <img>: imágenes.
  • <a>: enlaces.
  • <ul> y <li>: listas.

💻 Ejemplo de código HTML

<h1>Hola Mundo</h1>
<p>Mi primera página web</p>

🎨 ¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje que se utiliza para dar diseño y estilo a las páginas web creadas con HTML. Permite cambiar colores, tamaños, fuentes, márgenes y la disposición de los elementos.

💻 Ejemplo CSS

body{
    background-color: lightblue;
    font-family: Arial;
}
