☁️ GitHub

GitHub es una plataforma en la que podemos almacenar y gestionar proyectos de programación. GitHub Pages es un servicio que permite publicar páginas web de forma gratuita directamente desde un repositorio.

🌍 GitHub Pages

Cuando publicas una web en GitHub Pages, los archivos que subes se almacenan en un servidor. Ese servidor se encarga de mostrar tu página cuando alguien entra en el enlace. Así, cualquier persona en el mundo puede acceder a tu sitio web sin necesidad de instalar nada.

📤 Cómo subir el proyecto

  1. Crear un repositorio en GitHub.
  2. Subir los archivos HTML y CSS.
  3. Activar GitHub Pages en Settings.
  4. Compartir el enlace de la web.
